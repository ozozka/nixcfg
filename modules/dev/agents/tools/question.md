---
option-value: The value returned when selected
option-label: Display label for the option
option-description: Optional description shown below label
id: Unique identifier for this question
label: Short contextual label for tab bar, e.g. 'Scope', 'Priority' (defaults to Q1, Q2)
prompt: The full question text to display
options: Available options to choose from
allowOther: "Allow 'Type something' option (default: true)"
questions: Questions to ask the user
---

Ask one or more questions with selectable answers and optional custom input. One question uses a list; multiple questions use tabs.
